# The Value of Green Job Attributes: replication package

Andrea Marini, Fabio Landini and Ugo Rizzo

This repository will host the replication package of the paper "The Value of Green Job Attributes",
submitted to *Labour Economics*: the survey data, the programme-level measure of green content, and
the Stata code that reproduces all tables and figures. The files will be posted upon acceptance.

The experiment and its pre-analysis plan are registered in the AEA RCT Registry (trial 15138):
https://www.socialscienceregistry.org/trials/15138

Contact: Fabio Landini (corresponding author), fabio.landini@unipr.it
